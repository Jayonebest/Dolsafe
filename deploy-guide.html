  1. Go to github.com in your browser
  2. Click Sign up — top right

Create an index.html — the front door
Vercel needs a home page — this links all your screens together
▼
💡
When someone visits your URL with no file specified (e.g. dolsafe.vercel.app), Vercel shows index.html. You need to create this file.
  1. In your GitHub repo, click Add file → Create new file
  2. Name it exactly: index.html
  3. Paste this code into the editor:
<!-- DolSafe · Product Demo Hub --> <meta http-equiv="refresh" content="0; url=dolsafe-home.html">
This automatically redirects visitors to the DolSafe home screen.
  1. Click Commit new file

Import your GitHub repository
Connect the "dolsafe" repo — Vercel deploys it automatically
▼
  1. On the Vercel dashboard click Add New → Project
  2. Under "Import Git Repository" you should see your dolsafe repo listed
  3. Click Import next to it

Troubleshooting
Common issues and how to fix them in 30 seconds
!
Vercel shows a 404 error
The page cannot be found
▼
⚠️
Cause: You forgot to create index.html, or the filename has a typo.

Fix: Make sure all filenames in GitHub exactly match what you type in the URL. GitHub filenames are case-sensitive. dolsafe-home.html ≠ DolSafe-Home.html
!
Morning briefing does not load (blank screen)
The Claude API call is failing
▼
⚠️
Cause: The Claude API call in dolsafe-briefing.html needs an API key passed in the request headers — the current version relies on the claude.ai context. In a standalone deploy, the API call will fail.

Fix: The file already has fallback data built in — it shows cached briefing data if the API fails. For a demo this works fine. For a real app you would add your Anthropic API key to the fetch headers.
!
I do not see my repo in Vercel
Vercel cannot find the GitHub repository
▼
⚠️
Fix: In Vercel → Import Project → click "Adjust GitHub App Permissions" → on GitHub select All repositories → Save. Go back to Vercel and try again.
